# Concept Loom

When the user asks to learn, understand, study, practise, or be taught a subject, use the `concept-coach` skill. Use the connected `concept-loom` MCP tools for knowledge checkpoints, learning notebooks, and terminal-readable Mermaid or text diagrams.

Never reveal a checkpoint's expected keys or rationale before collecting the learner's response.

For one topic, a course from scratch, learning from supplied materials, resume, review, or practice, load `concept-coach` and route to the matching workflow. Learners can simply state their goal; do not require special syntax. For a course, ask one intake/diagnostic question at a time with Codex's native question UI when available, and save each answer before continuing. Preserve the exact roadmap revision through explicit approval. Offer a separate schedule after approval and report it as active only after a verified host receipt; otherwise explain the manual option. Show Mermaid directly in the conversation and use the inline learning view only when available.
