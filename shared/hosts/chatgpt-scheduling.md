# ChatGPT/cloud scheduling recipe

Treat cloud scheduling as unavailable until the current host proves both a native fresh-chat trigger and durable access to the same ConceptLoom workspace across runs. A capability report without persistent workspace access must receive the manual fallback.

If both capabilities exist, collect separate schedule consent, create the task through the native host UI, and bind only its confirmed receipt. Each run claims a single lesson, includes the returned bounded resume capsule, and waits for learner evidence. Never claim a cloud integration is ready based only on a local mock receipt.
