# Claude Code Desktop native scheduling recipe

Use scheduling only when the installed Claude Code Desktop exposes a native recurring task that starts a fresh chat and can reopen the same durable workspace. Ask ConceptLoom to validate the observed capabilities first. If unavailable, provide the generated manual launch instructions.

The learner separately approves the exact roadmap and the exact schedule. Create the native task only after both approvals. Bind it using the host's actual external ID and receipt fields; never synthesize a receipt from a proposed configuration. Each trigger claims one lesson and starts a new lesson chat. A timeout with unknown task/chat creation is reconciled before another create action.
